# Categorized team templates

There are 150 JSON teams in every `competitive`, `casual`, and `random` size
directory, from `1` through `6`: **2,700 teams** total. Each Pokémon has four
distinct moves. Files can be edited directly; keep party size equal to the folder.

Build and select these teams with `--team-profile` and optional `--team-size`.
See [the complete guide](../../../docs/team-profiles.md) for commands, category
definitions, held-item distributions and reproducible generation.
