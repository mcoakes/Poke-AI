# Pokémon sprites

386 default Pokémon sprites (National Pokédex 1–386) from
[PokeAPI/sprites](https://github.com/PokeAPI/sprites), commit `2ecb4eeacd5a1718621fc30f12772e3f60d830b9`.
Source files: `sprites/pokemon/1.png` through `386.png`. Images are included
locally so the team picker works offline.

See [upstream LICENCE.txt](LICENCE.txt). Pokémon names and artwork belong to
their respective owners; this project does not claim ownership of them.
The generation catalog supplies National Pokédex numbers for these names;
no image downloads or Node.js dependencies are needed at runtime.
